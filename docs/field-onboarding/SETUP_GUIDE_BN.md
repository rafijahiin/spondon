## ক অংশ — ফোনের ব্রাউজার দিয়ে (সহজ পদ্ধতি)

এটাই বেশিরভাগ কাজের জন্য যথেষ্ট। অ্যাপ লাগবে না।

### ধাপ ১ — হোয়াটসঅ্যাপে আসা লিংক চাপুন

আপনার ম্যানেজার আপনাকে হোয়াটসঅ্যাপে কয়েকটি লিংক পাঠাবেন। প্রতিটি লিংক একটি ফর্ম খুলবে — যেমন ক্লায়েন্ট নিবন্ধন, মাতৃমৃত্যু রিপোর্ট, ফিস্টুলা কেস।

লিংক দেখতে এইরকম —

```
https://ee.kobotoolbox.org/x/...
```

লিংকে চাপলে আপনার ফোনের ব্রাউজারে (Chrome বা Safari) ফর্ম খুলে যাবে।

### ধাপ ২ — ফর্ম পূরণ করুন

- প্রতিটি প্রশ্ন পড়ুন
- উত্তর লিখুন বা অপশন বাছুন
- লাল তারা (*) চিহ্নিত প্রশ্নগুলো অবশ্যই দিতে হবে
- ছবি তুলতে বললে ক্যামেরা আইকনে চাপুন
- **লোকেশন (GPS) চাইলে অনুমতি দিন** — এটা বাধ্যতামূলক

### ধাপ ৩ — সাবমিট চাপুন

ফর্মের শেষে সবুজ **Submit** বোতাম পাবেন। চাপলেই কাজ শেষ।

ইন্টারনেট না থাকলে ব্রাউজার ফর্মটি জমা করতে পারবে না — এক্ষেত্রে নিচের "খ অংশ" দেখুন।

### ধাপ ৪ — ম্যানেজারের অনুমোদন

আপনি সাবমিট করার সাথে সাথে আপনার ম্যানেজারের কাছে নোটিফিকেশন যাবে। তিনি দেখে অনুমোদন দিলে তথ্যটি ড্যাশবোর্ডে চলে যাবে।

আপনার আলাদা করে কিছু করার নেই।

## খ অংশ — KoboCollect অ্যাপ (ইন্টারনেট না থাকা এলাকার জন্য)

আপনি যদি এমন জায়গায় কাজ করেন যেখানে মোবাইল নেট প্রায়ই থাকে না — তবে KoboCollect অ্যাপ ব্যবহার করুন। অ্যাপ ফর্মটা অফলাইন সেভ করে রাখবে, পরে নেটে এলে নিজে থেকেই পাঠিয়ে দেবে।

### ধাপ ১ — অ্যাপ ইনস্টল করুন

Google Play Store-এ গিয়ে **"KoboCollect"** লিখে সার্চ করুন। সাদা পটভূমিতে নীল K লোগো — সেটাই ইনস্টল করুন।

সরাসরি লিংক —
```
https://play.google.com/store/apps/details?id=org.koboc.collect.android
```

### ধাপ ২ — সার্ভার সেট করুন

অ্যাপ খুলে —
1. উপরে ডানদিকের তিন-ডট মেনুতে চাপুন
2. **General Settings → Server** বেছে নিন
3. **URL** এর ঘরে লিখুন —
   ```
   https://kf.kobotoolbox.org
   ```
4. **Username** এর ঘরে আপনার ম্যানেজার যে নামটি দিয়েছেন সেটা লিখুন
5. **Password** এর ঘরে পাসওয়ার্ড লিখুন
6. সেভ চাপুন

### ধাপ ৩ — ফর্ম ডাউনলোড করুন

মূল মেনুতে ফিরে যান। **Get Blank Form** চাপুন। সবগুলো ফর্মে টিক দিন। **Get Selected** চাপুন।

এখন ফোন থেকে নেট চলে গেলেও আপনি ফর্ম পূরণ করতে পারবেন।

### ধাপ ৪ — ফর্ম পূরণ ও সেভ

মূল মেনুতে **Fill Blank Form** চাপুন → যে ফর্মটি দরকার সেটা বেছে নিন → পূরণ করুন → **Save Form and Exit** চাপুন।

### ধাপ ৫ — নেটে এলে পাঠান

নেট এলে অ্যাপ খুলে **Send Finalized Form** চাপুন। সব জমে থাকা ফর্ম একসাথে চলে যাবে।

## জরুরি কিছু কথা

- **লোকেশন অবশ্যই দিন** — না দিলে ম্যানেজার সাবমিশন গ্রহণ করতে পারবেন না
- **ছবি ৫০০ KB-এর বেশি না** — ছবি তুলতে বললে ফোনের ক্যামেরা ব্যবহার করুন, আলাদা গ্যালারির বড় ছবি না
- **একই ক্লায়েন্টের জন্য একাধিকবার সাবমিট করবেন না** — সিস্টেম ডুপ্লিকেট ধরবে এবং ম্যানেজারের কাছে সতর্কতা যাবে
- **সমস্যা হলে** — আপনার ম্যানেজার বা ফোকাল পয়েন্টকে হোয়াটসঅ্যাপে ছবি পাঠিয়ে জানান

## সমস্যা সমাধান

| সমস্যা | কী করবেন |
|---|---|
| ফর্ম লোড হচ্ছে না | পেজ রিফ্রেশ করুন (ব্রাউজারের উপরে ↻ চিহ্ন) |
| লোকেশন আসছে না | ফোনের সেটিংসে গিয়ে ব্রাউজার বা KoboCollect-কে লোকেশন অ্যাক্সেস দিন |
| Submit চাপলে কিছু হচ্ছে না | ইন্টারনেট চেক করুন। নেট না থাকলে অপেক্ষা করুন। |
| ছবি যোগ হচ্ছে না | ছোট ছবি তুলুন, বা পুরোনো ছবি মুছে নতুন তুলুন |
| ভুল করে ফেললাম | চিন্তা করবেন না। ম্যানেজার সাবমিশন রিজেক্ট করবেন। আপনি আবার সঠিকভাবে দিন। |
