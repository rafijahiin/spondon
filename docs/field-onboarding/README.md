### Step 3 — verify reception (48 hours after broadcast)
Watch the Submissions Inbox at `/approvals` on the dashboard. If submissions arrive from at least 25 of 40 staff within 48 hours, the rollout worked. If fewer, focal calls the silent ones individually.

## Why no KoboCollect Android app (by default)

The forms are exposed as **public Enketo web URLs** — anyone with the link can submit from any phone browser. Location, photos, signatures all work in the browser. KoboCollect (the Android app) is only needed for:
- Areas with no signal at submission time (form gets queued, syncs later)
- Staff doing >10 forms per day where typing speed matters

The guide covers both paths. Default is browser; KoboCollect is the optional Section B.

## What field staff don't have

- Dashboard login (they don't need it — submissions appear in the manager's approval queue)
- Telegram account (not required for v1; we can add Telegram acknowledgements later if useful)
- A printed manual (the WhatsApp message + Bangla PDF is enough)
